# Zero Agent 記憶アーキテクチャと BCNOFNe 参考実装

更新: 2026-10-29

## 目的
BCNOFNe のエピソード記憶・自律ループの構想を参考に、Android Zero Agent に観測・操作・結果を保存し再利用する仕組みを設ける。BCNOFNe の「7層」は設計上の構想であり、全層が動作する完成品として扱わない。Python 実装を直接移植していない。

## 実装した記憶

| 層 | ファイル | 保存内容 | 期限 |
|---|---|---|---|
| 画面キャプチャ | GuidedBrowser.kt | PNG | 24時間経過後、次の起動・撮影で削除 |
| 短期視覚記憶 | VisualMemory.kt | 画像認識結果、URL、工程、時刻 | 24時間 |
| 長期視覚記憶 | VisualMemory.kt | ユーザーが昇格した観測メモ | 明示的削除まで（上限100件） |
| エピソード記憶 | EpisodeMemory.kt | 目的、ホスト、操作、前後URLパス、結果 | 最新200件 |

画像は OpenRouter の画像対応モデルへ送信され、返された文章をローカルの JSON に保存する。**画像自体は長期記憶に保存しない。** 視覚記憶は検索・閲覧・長期保存・削除が可能。エピソード記憶は一覧表示・全削除が可能。

## 実行フロー
1. WebView のDOMと画面を観測。
2. 必要に応じて画像認識し、視覚記憶に登録。
3. 現在の工程・URLから視覚記憶と過去の操作結果を検索。
4. AIに過去情報を**信頼できない参考情報**として渡す。
5. 安全な同一ホストHTTPS閲覧リンクのみ移動。
6. 移動前後のURLを記録する。URL変化は「unknown」、変化なしは「failed」。**URL変化だけで成功と判定しない。**
7. 工程達成は別の観測・判定処理で確認する。

## プライバシー・制限
- パスワード、Cookie、トークン、決済操作は記憶に含めない設計。URL全体に秘密情報が含まれる可能性はあるため、運用前に追加のサニタイズが必要。
- 現在のJSON保存は暗号化されていない。機密ページで撮影・保存しないこと。
- PNG削除は端末が閉じている間に厳密に24時間で走るものではない。
- 画像認識には対応モデルとAPI利用料が必要。
- 記憶の関連性検索は簡易キーワード方式で、ベクトル検索・意味検索ではない。
- エピソード記憶は自動調査のリンク移動が対象。Chrome AccessibilityService全操作への統合は未実装。
- AIに渡す画面や記憶内の命令は指示として扱わない。重要操作は人間の承認を維持。

## 実装進捗（2026-10-29：観測→操作→検証→経験学習）

| 要件 | 状態 | 実装・制約 |
|---|---|---|
| Xで市場調査を開始 | 一部実装 | 工程にXが含まれると x.com をWebViewで開く。X専用の検索語生成や検索送信の完全自動化は未実装 |
| 検索画面を認識 | 実装 | DOM要素一覧・本文を観測。画像認識は対応モデル利用時に実行 |
| 検索操作を実行 | 一部実装 | AIがクリック・入力を提案し、ユーザーが承認して実行。自動調査は同一ホストHTTPSの閲覧リンクだけを最大5件たどる。検索フォームの自動送信はしない |
| 結果が表示されたか検証 | 一部実装 | 遷移後のURL・DOM・本文を再観測し、AIで現在工程の達成を判定。検索結果固有の正確性検証や外部事実確認は未実装 |
| 成功・失敗・原因を記憶 | 実装（自動閲覧リンク） | EpisodeMemory が success / failed / unknown と理由を最大200件記録。既存データの reason 欠損は空文字として読み込み |
| 次回、似た画面で過去経験を参照 | 一部実装 | 同じホストまたは類似工程から記憶を検索し、AIに参考情報として渡す。画面類似度のベクトル検索は未実装 |
| 視覚短期・長期記憶 | 実装 | 画像認識テキストを短期保存、手動で長期昇格。スクリーンショット画像の長期保存はしない |
| 安全停止 | 実装 | 同一画面・リンク再訪、異なるホスト、危険操作、上限回数で停止。フォーム送信・決済・ログインは自動実行しない |
| ビルド・実機動作確認 | 未検証 | GitHub ActionsのPRビルド結果とAndroid端末での検証が必要 |

### 判定ルール
- **success**: ページ遷移後の内容からAIが工程達成を確認した場合のみ。
- **failed**: ページ変化なし、または別ホスト遷移を検出した場合。
- **unknown**: ページは変わったが工程達成を確認できなかった場合。
- AIの達成判定は誤判定し得る。外部サービスの実際の成果を保証しない。
- 記憶は端末内JSONで暗号化されない。パスワード・個人情報が混入しないよう追加のマスキングと同意設定が必要。
- 自動操作とユーザー承認による操作の記録範囲は異なる。承認操作の完全なエピソード記録は今後の課題。

### 手動検証項目
1. Xの検索画面で要素と画像認識ができるか
2. 閲覧リンクを移動したとき success / failed / unknown が適切に分かれるか
3. 同じ画面を再訪したとき安全停止するか
4. アプリを再起動してもエピソード記憶が残るか
5. 同じホスト・工程で過去の結果がAIの参考情報に含まれるか
6. 行動履歴の全削除と視覚記憶の期限切れが正しく動くか
7. ログイン・決済・投稿・検索送信が無断実行されないか

## Xネイティブアプリのユーザー補助対応（2026-10-29）
- X Androidアプリのパッケージ `com.twitter.android` をChromeAssistServiceの対象に追加。
- 画面検出、操作候補の読み取り、承認クリック、画面指紋、お手本記録のChrome固定判定を対象パッケージ判定に統一。
- XアプリにはChromeのアドレスバーがないため、URL取得ができない場合は「取得不可」として扱い、URLを推測しない。
- 認証・決済・投稿・送信・削除などの保護操作は従来どおり禁止。ユーザーの許可なく検索や投稿を送信しない。
- **未検証**: Xアプリ実機での画面認識、Androidビルド、Google Playの審査。端末によって画面構造が異なる可能性あり。
