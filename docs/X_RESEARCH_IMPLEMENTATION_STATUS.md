## 絶対条件
**「調査完了」は、検索語に関連する実投稿を特定し、投稿ID/URL・本文・いいね数・スクリーンショットの紐付けを検証し、保存に成功した場合だけ表示する。** 操作の成功、画面変化、検索語の表示、スクショ撮影だけでは完了扱いにしない。現状のコードはこの条件を満たさず、必ず「調査未完了」とする。

## 現時点の実際の判定
- `hasRelevantResult(query)`: 画面の**単一ノードラベル**に検索語がすべて含まれるかを確認するだけ。検索欄・見出し・広告・他の投稿を誤検知する可能性がある。画像そのものの意味は判定していない。
- `xCollect`: いいね数を含むラベルを候補保存するが、スクショや投稿IDと一意に結び付かない。
- `startXResearch`: 調査を始めても**未検証**と表示。画面保存件数を成功件数と呼ばない。
- 2026-10-30現在、APKビルド成功・X実機動作・画像保存・関連性判定は未検証。ユーザー提供の画面では `comで同じ顔` など不正な検索語が観測され、修正はしたが再現テストは未実施。

## 未実装・次の実装順
1. **投稿単位の抽出**: アクセシビリティツリーの投稿カードを特定。投稿ID/URL・著者・本文・いいね数を同一カード内から抽出し、カード以外の検索欄や操作UIを除外。URLが取得できなければ未検証とする。
2. **証拠紐付けの完成**: 現状は候補ラベルとスクショURIを同一行に保存する初期実装まで。 投稿ID/URL、検索語、スクショのcontent URI、撮影日時、画面/投稿の位置情報、抽出本文、いいね数、判定根拠を同一DBレコードに格納。必要ならカード単位に切り抜く。スクショの中に該当カードが存在することを検証する。
3. **関連性検証**: テキスト判定に加え、画像の内容とユーザーの調査目的をマルチモーダルAI等で照合。モデル未設定・失敗・不確実な場合は `unknown`、不一致は `irrelevant`。AIの判定も誤り得るため根拠を保存。
4. **検証状態管理**: `pending/searching/captured/verified/irrelevant/failed` を区別。実際に保存された `verified` 件数だけで完了判定。中断・画面変化・スクショ失敗・検索失敗は完了禁止。
5. **バックアップ対象拡大**: キーワードSQLiteだけでなく投稿DB・画像をZIP等にまとめ、Downloadsにエクスポート。復元時に形式・整合性・重複を検査し、画像URIを再作成。
6. **UI**: キーワード別に「確認済み投稿数」「未確認数」「スクショ」「投稿URL」「いいね数」「判定理由」を表示。画像を開いてユーザーが検証できること。
7. **テスト**: Kotlin単体テスト（URL/命令の除去、語句抽出、空結果、誤判定、DB再生成）→ GitHub Actionsビルド → Android実機でX検索・スクショ・再インストール復元まで確認。

## 完了判定の受入条件
- 検索対象がX公式アプリ上で実際に表示され、検索クエリと一致。
- **実投稿**が特定でき、本文/いいね数/投稿URL/スクショが同一レコードに保存される。
- 投稿内容が検索目的に関連すると判定され、判定根拠を表示できる。
- 保存したスクショを再度開ける。少なくとも1件の `verified` 記録が存在する。
- 調査が途中停止した場合は「部分完了/未完了」と表示し、成功を偽らない。

## セキュリティ・プライバシー
ログイン・パスワード・決済・投稿操作を自動実行しない。スクショには個人情報が映る可能性があるので、共有・クラウド送信はユーザー許可を要する。APIキーをバックアップに平文で含めない。

## 2026-10-30 追加: アンインストール後の調査ZIP復元
- `ResearchArchive.kt` を追加。ファイル選択画面で指定した外部保存先へ `zero-agent-research-full.zip` を出力する。
- ZIPには検索語DBのJSON、未検証証拠DBのJSON、参照するPNG画像本体を格納。画像が読み込めない場合はエラーとして扱い、正常な完全バックアップとは報告しない。
- 復元時はZIP形式・画像エントリ名・サイズ・PNG署名を検査し、画像を `Downloads/ZeroAgent` に再作成。新しいcontent URIを証拠DBに保存。検索語は既存の `importJson` を使用し、証拠は `captured` 状態としてマージ。
- `MainActivity.kt` に「画像を含む調査ZIPをバックアップ」「調査ZIPを復元（再インストール後）」を追加。
- **注意**: XResearchMemoryのSharedPreferences履歴、アプリ設定、APIキーはこの調査ZIPの対象外。設定バックアップは別機能。ZIPには画面画像や個人情報が含まれ得るため第三者と共有しない。
- **未検証**: Android APKビルド、実機でのZIP出力、アンインストール→再インストール→復元、投稿関連性判定。完全復元の動作保証はまだできない。
