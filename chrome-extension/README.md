# Zero Agent Chrome Controller (prototype)

Chrome > 拡張機能 > デベロッパーモード > パッケージ化されていない拡張機能を読み込む > chrome-extension フォルダを選択。

現在は手動操作の検証版です。開いているタブの文字と操作可能な要素を読み取り、CSS セレクターでクリック・入力・スクロールできます。AIによる自律操作・Android連携・画面画像認識は未実装です。chrome:// ページなどChromeが制限するページでは動作しません。

次段階: AIへ構造化ページ情報を渡し、許可された操作のみをJSONで受け取り、確認画面を挟んで実行する。パスワードや認証情報をAIへ送らず、送信・購入・削除操作には都度承認を要求する。
