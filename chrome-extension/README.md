# Zero Agent Chrome Controller — AI-assisted prototype

1. Chromeの拡張機能画面 chrome://extensions でデベロッパーモードを有効にする。
2. この chrome-extension ディレクトリを「パッケージ化されていない拡張機能」として読み込む。
3. 通常のWebページで拡張機能を開き、OpenRouter APIキー、モデルID、指示を入力する。
4. 「AIに次の操作を提案させる」で提案を確認し、問題なければ承認して実行する。

**制限**: 現時点ではWindows/デスクトップChrome向けの一手ずつのAI提案です。連続自律実行、Android操作、画像認識は未実装です。入力値を含む本文ではなく可視テキストと一部要素メタデータをOpenRouterに送ります。ページのテキストに個人情報がある場合は送信しないでください。キーは保存しませんが、OpenRouterへのAPIリクエストには使用します。外部送信、購入、削除、ログイン操作は実行しないでください。提案は必ず人間が確認してください。CSS IDを持たない要素はAIクリックの対象外です。ブラウザ保護ページでは動作しません。
